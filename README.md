# TOUCH THE GRASS

**▶ Play: https://lukaasatiani1.github.io/touch-the-grass/**

A tribute to the classic Snake game. You are a snake of empty days inside a contribution graph, and
the obstacles are generated by Conway's Game of Life: commits are born, spread and die by its rules,
so you can always read where they'll be next. The whole point is to avoid making a commit. Touch grass
to grow bigger, and stay grey until 23:59.

- Arrow keys / WASD, or tap, to steer
- Outlined cells are born next generation, dim cells die
- Nothing can be born under you, so the danger is ahead: don't run into green, don't bite your tail
- Touch grass to grow bigger
- `M` toggles sound

Because contribution graphs are extremely overrated.
Made for [my profile](https://github.com/LukaAsatiani1).

The page is generated from the profile repo's build scripts; this repo only serves it with GitHub Pages.
